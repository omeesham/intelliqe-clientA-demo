## Authentication

### TC-001 — Verify login page displays all required elements on load
**Feature:** User Login · **Priority:** P0 · **Type:** smoke · **Severity:** Critical

Confirms the login page renders the branding, both input fields, the Login button, and the Forgot Password link so users can authenticate. Covers acceptance criterion AC1 which gates all downstream login behavior.

**Precondition:** The OrangeHRM QA environment is available and the login URL is reachable.

**Steps:**

1. Navigate to https://opensource-demo.orangehrmlive.com/web/index.php/auth/login → Expected: The login page loads without error
2. Observe the branding area at the top of the login card → Expected: The OrangeHRM logo is displayed
3. Locate the input field labelled 'Username' → Expected: The Username field is displayed and enabled
4. Locate the input field labelled 'Password' → Expected: The Password field is displayed and enabled
5. Locate the 'Login' button and the 'Forgot your password?' link → Expected: The Login button and the 'Forgot your password?' link are both displayed

**Expected Result:** The login page displays the OrangeHRM logo, Username field, Password field, Login button, and Forgot your password? link.

**Tags:** smoke, ui, auth
